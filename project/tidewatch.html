    TidewatchTidewatch

    Sensor kit and live dashboard for harbour moorings

    Year2026
    StatusIn progress
    TypePersonal project
    LanguagesPython · Rust · JavaScript
    [ 01 / 05 ]·About the project

    A hand-soldered sensor board (RP2040, e-ink, LoRa) that reports line tension and water level from the pier, plus a web dashboard and a watch tile to keep an eye on it.

    Tidewatch started as a weekend question: how hard is it to know, from the sofa, whether my neighbour's boat is pulling on its lines in a storm? The answer was a small board bolted to the pier, a LoRa link and a dashboard.

    The firmware runs MicroPython on an RP2040, sleeps most of the time and wakes on change. Readings land in a tiny Rust service and stream to a browser dashboard and a smartwatch tile.
